# 安全规范

## 密钥与环境变量

- 禁止在代码、commit、PR 描述中硬编码私钥、助记词、API Key 或数据库连接串。
- 前端需要的环境变量统一通过 `.env.local`（本地）读取，提供 `.env.example` 作为模板，真实值不得提交仓库。
- 当前阶段无真实钱包/数据库/合约接入，不应出现任何真实密钥或 RPC 私钥；Mock 数据直接写在代码或本地 JSON 中即可。

## 敏感文件

- `.gitignore` 已忽略 `.env*`（示例文件除外）、构建产物和依赖目录，新增敏感文件类型时同步更新 `.gitignore`。
- 提交前如发现 `git status` 中出现不应追踪的文件（尤其文件名看似无害但可能含密钥的配置文件），先检查内容再决定是否加入版本控制。

## 合约相关

- 遵循 `contracts/` 中已体现的安全模式：Checks-Effects-Interactions、`nonReentrant` 重入锁、访问控制。
- 不移除或弱化现有合约的安全检查（如 `require` 校验、重入锁）。
