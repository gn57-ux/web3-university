# 个人中心 — 需求规格

## 概述

实现个人中心页面：用户资料头部、签名修改用户名弹窗（Mock 签名）、四个功能 Tab（已购课程/学习进度/NFT 证书/购买记录），均为前端 Mock 交互。

## 项目信息

- 项目名: web3-university
- 架构类型: 单体仓库：Next.js 前端（纯 UI + Mock 交互）

## 需求版本

| 日期 | 版本 | 说明 |
| --- | --- | --- |
| 2026-08-12 | v1 | 初始需求 |
| 2026-08-13 | v2 | 头像地址接入真实 Privy 身份（随 1.wallet-auth 变更联动），新增未登录门禁 |

## 用户故事

- 作为学生，我想要在个人中心查看我的钱包地址、用户名和 YD 余额，以便确认当前账户信息。
- 作为学生，我想要修改用户名并通过 Mock 钱包签名确认，以便体验真实产品中"签名修改用户名"的交互流程。
- 作为学生，我想要分别查看已购课程、学习进度、NFT 证书和购买记录，以便全面了解自己的学习与资产状况。
- `[v2 新增]` 作为访客，若我还没有登录就访问个人中心，我想要看到明确的登录提示而不是别人的/虚假的账户信息，以便理解这是我自己的个人资料页。

## 功能需求

1. [F-001] 个人信息头部：头像、用户名（默认如 "Web3Student"）、角色徽标（学生）、钱包地址缩略显示、YD 余额。`[v2 修改]` 地址改为真实 `useWallet().address`（登录后才有值）；YD 余额继续读 `useWallet().ydBalance`（Mock，不变）；用户名/角色徽标继续本地 Mock 状态（不变，不因登录状态重置）。
2. [F-002] "修改用户名"入口，点击弹出 Modal：文本输入框 + 取消按钮 + "钱包签名确认"按钮，点击确认后进入 Mock 签名等待态，成功后更新页面头部用户名并关闭 Modal。
3. [F-003] Tab 导航：已购课程 / 学习进度 / NFT 证书 / 购买记录，默认展示第一个 Tab。
4. [F-004] 已购课程 Tab：课程卡列表 + "继续学习"入口（跳转学习中心）。**例外**（实现阶段确认，见 AC-004）：当本地无真实购买记录、展示的是本 feature 自带的默认 fixtures 时，这些课程并未被 `lib/mock/purchaseStore.ts` 记录为真实已购，若入口仍跳转学习中心会被购课门禁拦截（"个人中心显示已购、点进去却提示未购买"）；此时入口退化为"查看课程详情"（跳转 `/courses/{id}`），只有真实购买记录存在时入口才跳转学习中心。
5. [F-005] 学习进度 Tab：每门已购课程对应一条进度条。
6. [F-006] NFT 证书 Tab：证书卡片列表，含虹彩边框视觉、Token ID、课程名称。
7. [F-007] 购买记录 Tab：交易记录表格，列包含课程名称、价格（YD）、购买时间、交易哈希（缩略显示 + 区块浏览器链接占位，Mock 不可真实跳转或跳转到占位地址）。
8. `[v2 新增]` [F-008] 登录门禁：`/profile` 页面挂载后读取 `useWallet().connected`；未登录时不渲染资料头部/Tab 内容，改为展示门禁区块（视觉复用学习中心 `PurchaseRequiredGate` 的模式：图标 + 提示文案 + 登录按钮），点击登录按钮触发 `useWallet().login()`；登录成功后自动切换为完整个人中心内容，无需手动刷新页面。

## 非功能需求

- 性能: 无特殊要求（数据量小）。
- 安全: 无真实签名操作，Mock 签名仅为 UI 等待态模拟。
- 兼容性: Tab 在移动端可横向滚动；购买记录表格在移动端转为卡片式布局或提供横向滚动容器。

## 验收标准

- [ ] [AC-001] `[v2 修改]` 已登录状态下，页面头部信息与 Stitch 截图字段一致（头像/用户名/角色/真实地址/Mock 余额）。
- [ ] [AC-002] 点击"修改用户名"→输入新用户名→点击签名确认→Mock 等待后页面用户名更新。
- [ ] [AC-003] 四个 Tab 均可正确切换并展示对应内容，无内容丢失或报错。
- [ ] [AC-004] 若本地已有 feature 4 写入的 Mock 购买记录（`localStorage`），"已购课程"与"购买记录" Tab 优先展示该数据；若不存在，则展示本 feature 自带的默认 fixtures，保证独立可验收。
- [ ] [AC-005] `[v2 新增]` 未登录访问 `/profile` 时展示登录门禁（不泄露/不展示任何资料头部或 Tab 内容），点击门禁内的登录按钮触发真实 Privy 登录；登录成功后无需刷新页面即可看到完整个人中心内容；退出登录后重新回到门禁态。
