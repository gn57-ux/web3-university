# 学习中心 — 需求规格

## 概述

实现课程学习页面：视频播放区（Mock）、章节进度、评论区、完课与证书铸造中提示，均为前端 Mock 交互。

## 项目信息

- 项目名: web3-university
- 架构类型: 单体仓库：Next.js 前端（纯 UI + Mock 交互）

## 需求版本

| 日期 | 版本 | 说明 |
| --- | --- | --- |
| 2026-08-12 | v1 | 初始需求 |

## 用户故事

- 作为访客/未购课用户，若我直接访问某课程的学习页面，我想要看到明确的"请先购买"提示而非完整课程内容，以便理解需要先完成购买。
- 作为已购课学生，我想要观看课程视频并查看章节进度，以便按顺序学习。
- 作为已购课学生，我想要在评论区看到其他学员的讨论并发表自己的评论，以便交流学习心得。
- 作为已购课学生，我想要在完成所有章节后看到清晰的完课与证书铸造提示，以便了解下一步该做什么。

## 功能需求

1. [F-001] 面包屑导航：首页 > 课程广场 > 课程分类 > 当前课程/章节。
2. [F-002] 视频播放区（Mock）：封面图占位 + 播放/暂停控制 UI + 进度时间显示（如 12:34 / 45:00），无真实视频流。
3. [F-003] 代码示例区块：展示一段只读、语法高亮的示例合约代码片段。
4. [F-004] 章节列表与进度：5 个模块，含已完成（勾选图标）、当前播放中、未解锁（锁图标）三种视觉态，整体进度条显示完成百分比。
5. [F-005] 评论区：展示 Mock 评论列表（含发言人、时间、内容），提供发表评论的输入框（纯前端状态，不持久化到服务端）。
6. [F-006] 完课状态提示：当模块进度达到 100%（或用户手动触发"标记完成"用于演示）时，展示"完课确认中/证书铸造中"的 Mock 文案，并提供跳转个人中心的按钮。
7. [F-007] 购课门禁：进入 `/learn/{courseId}` 时，读取 [[4.course-detail-mock-purchase]] 的共享 Mock Store（`purchaseStore.getPurchases()`）判断当前课程是否已购买；未查到购买记录时，不渲染视频/章节/评论等完整内容，改为展示"请先购买本课程"的锁定提示区块，并提供跳转课程详情页（`/courses/{courseId}`）完成购买的按钮。

## 非功能需求

- 性能: 视频区域为静态占位，不加载真实视频资源，避免不必要的带宽消耗。
- 安全: 无。
- 兼容性: 移动端视频区与章节列表需堆叠为单列，不出现横向遮挡。

## 验收标准

- [ ] [AC-001] 页面结构与 Stitch 截图一致（面包屑→视频区→代码示例→章节进度→评论）。
- [ ] [AC-002] 章节列表中已完成/当前/锁定三种状态视觉区分明确。
- [ ] [AC-003] 在评论输入框输入内容并提交后，新评论出现在列表顶部（纯前端状态，刷新后可丢失）。
- [ ] [AC-004] 触发完课演示操作后，展示证书铸造中的 Mock 提示与跳转个人中心按钮。
- [ ] [AC-005] 未在共享 Mock Store 中查到该课程购买记录时，访问 `/learn/{courseId}` 展示锁定提示区块（而非完整课程内容），且提供跳转课程详情页的按钮；手动通过课程详情页完成 Mock 购买后再次访问同一课程，应正常展示完整学习内容。
