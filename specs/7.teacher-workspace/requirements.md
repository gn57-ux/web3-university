# 老师工作台 — 需求规格

## 概述

实现老师工作台页面：欢迎区与关键指标、提交新课程、我的课程列表及状态管理（草稿/待审核/已上架），均为前端 Mock 交互。

## 项目信息

- 项目名: web3-university
- 架构类型: 单体仓库：Next.js 前端（纯 UI + Mock 交互）

## 需求版本

| 日期 | 版本 | 说明 |
| --- | --- | --- |
| 2026-08-12 | v1 | 初始需求 |

## 用户故事

- 作为老师，我想要在工作台看到我的课程数量、学生总数和待处理事项，以便快速了解整体状况。
- 作为老师，我想要提交新课程资料，以便发起课程上架流程。
- 作为老师，我想要查看我提交的课程当前状态（草稿/待审核/已上架），以便跟进进度。

## 功能需求

1. [F-001] 欢迎区块："欢迎回来, {老师名} 老师" + 说明文案 + 关键指标（课程数、学生总数、待处理事项数）+ "提交新课程"按钮。
2. [F-002] 提交新课程表单/弹窗：课程名称、描述、封面（占位上传或 URL 输入）、价格、章节占位字段，提交后 Mock 新增一条状态为"草稿"或"待审核"的课程记录。
3. [F-003] 我的课程列表：卡片形式展示每门课程，含状态徽标（已上架/待审核/草稿）、简介、进度/学生数（已上架课程展示学生进度百分比与人数）。
4. [F-004] 课程卡操作项：编辑（打开表单预填）、查看数据分析入口（Mock，无真实统计接口，可跳转占位页或展示 Mock 数据面板）。
5. [F-005] 草稿课程展示完成度与"提交审核"操作，点击后 Mock 将状态从"草稿"切换为"待审核"。
6. [F-006] 空状态：当老师暂无课程时，展示提示文案与"提交新课程"引导 CTA。

## 非功能需求

- 性能: 无特殊要求。
- 安全: 页面本身不做真实身份校验（当前阶段无登录），可在页面顶部/文案中注明"演示模式：默认以老师视角展示"。
- 兼容性: 指标卡与课程卡在移动端单列堆叠。

## 验收标准

- [ ] [AC-001] 页面结构与 Stitch 截图一致（欢迎区→指标→我的课程列表）。
- [ ] [AC-002] 提交新课程表单填写并提交后，新课程出现在"我的课程"列表中，初始状态为草稿或待审核（二选一，需在 design.md 中明确并保持一致）。
- [ ] [AC-003] 草稿课程点击"提交审核"后状态切换为"待审核"。
- [ ] [AC-004] 三种课程状态（已上架/待审核/草稿）在列表中有明确区分的视觉徽标。
