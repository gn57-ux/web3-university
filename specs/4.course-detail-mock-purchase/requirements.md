# 课程详情与模拟购买 — 需求规格

## 概述

实现课程详情页（课程介绍、大纲、学员评价）与模拟购买流程（授权→购买两阶段状态机），完全基于前端 Mock，不发起任何真实链上交易。

## 项目信息

- 项目名: web3-university
- 架构类型: 单体仓库：Next.js 前端（纯 UI + Mock 交互）

## 需求版本

| 日期 | 版本 | 说明 |
| --- | --- | --- |
| 2026-08-12 | v1 | 初始需求 |
| 2026-08-13 | v2 | 购买面板的"未连接钱包"/"需切换网络"前置状态接入真实 Privy 身份层（随 1.wallet-auth 变更联动），余额/授权/购买阶段保持 Mock |

## 用户故事

- 作为学生，我想要查看课程详细介绍与大纲，以便判断是否购买。
- 作为学生，我想要看到清晰的购买状态（未连接钱包/余额不足/待授权/待购买/已购买），以便理解当前需要做什么操作。
- 作为学生，我想要体验「授权 → 购买」两阶段交易的视觉反馈，以便熟悉真实链上购买流程的交互方式（即使当前为 Mock）。

## 功能需求

1. [F-001] 课程详情头部：标题、讲师信息、难度徽标、课程简介。
2. [F-002] 课程大纲：5 个可展开/收起的模块列表（如「以太坊与 EVM 简介」「Solidity 基础」「函数与修饰符」「高级模式」「安全 101」）。
3. [F-003] 学员评价区块：至少 2 条 Mock 评价（含星级评分）。
4. [F-004] 购买面板需支持以下状态并正确切换视觉呈现：未连接钱包 / 需切换网络 / YD 余额不足 / 待授权 / 授权中 / 待购买 / 购买中 / 已购买（显示"开始学习"）。`[v2 修改]` 「未连接钱包」「需切换网络」两态改由真实 `useWallet()` 驱动（`connected`/`network` 来自 Privy），不再是 Mock 状态；「YD 余额不足」及之后的授权/购买/已购买阶段**保持 100% Mock 不变**（不接入 YD 合约/购买合约）。
5. [F-005] 两阶段交易按钮：点击「授权 4 YD」进入授权中 Mock 等待态（模拟异步延时），成功后按钮形态过渡为「购买课程」；点击后进入购买中 Mock 等待态，成功后变为「开始学习」。
6. [F-006] 购买成功后，将该课程加入 Mock 购买记录（写入前端共享 Mock Store，如 `localStorage` 或内存 Context），供其他 feature（如个人中心、学习中心）按需读取，但不作为其验收的强依赖。
7. [F-007] 「开始学习」按钮跳转至学习中心页面路由。
8. [F-008] 「YD 余额不足」态需提供页面内可点击的 Mock「领取 YD」按钮（对应 PRD 的 Faucet 流程），点击后将钱包余额设置为满足本课程所需金额，使真实用户仅通过页面交互（无需借助开发者工具）即可从余额不足态推进到待授权态；不能仅依赖 `useMockWallet().setYdBalance()` 这一底层 API 存在，必须有可见、可点击的 UI 入口。

## 非功能需求

- 性能: Mock 异步等待时长应可控（建议 800ms-1500ms），避免用户感知过长的假等待。
- 安全: 无真实资金操作；所有状态均为前端模拟，不得引入任何真实钱包 SDK 或合约调用代码。
- 兼容性: 购买面板在移动端应吸底或以合理位置展示，不遮挡主要内容。

## 验收标准

- [ ] [AC-001] 课程详情页信息（标题/讲师/大纲/评价）与 Stitch 截图一致。
- [ ] [AC-002] `[v2 修改]` 在**尚未购买**该课程时，依次触发状态变化（真实 Privy 登录 → 若非 Sepolia 触发 `switchToSepolia()` → 已连接但 Mock 余额不足 → 点击页面内「Mock 领取 YD」按钮使余额充足）时，购买面板文案与可操作按钮随之正确变化；从"余额不足"到"余额充足"这一步必须能通过页面内可见按钮完成，不依赖开发者工具或未渲染的 API 调用（这一条不变，因为余额部分仍是 Mock）。
- [ ] [AC-003] 点击「授权」按钮后出现授权中态，随后自动流转为「购买」按钮态（无需刷新页面）。
- [ ] [AC-004] 点击「购买」按钮后出现购买中态，随后自动流转为「开始学习」态。
- [ ] [AC-005] 「开始学习」正确跳转至学习中心路由。
- [ ] [AC-006] 购买成功后刷新页面或重新进入 `/courses/{courseId}`，购买面板仍直接展示「开始学习」，不会退回未购买前置状态（未连接/错误网络/余额不足/未授权）。
- [ ] [AC-007] 购买成功后，即使之后断开 Mock 钱包连接、切换到错误网络或 YD 余额降为 0，购买面板仍保持「开始学习」态，不被前置条件状态覆盖。
