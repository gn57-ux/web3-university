# 首页 — 需求规格

## 概述

实现 Web3 University 首页的静态 UI 与 Mock 交互：Hero 区、关键指标、学习路径说明、精选课程展示，均基于 Stitch 设计稿还原。

## 项目信息

- 项目名: web3-university
- 架构类型: 单体仓库：Next.js 前端（纯 UI + Mock 交互）

## 需求版本

| 日期 | 版本 | 说明 |
| --- | --- | --- |
| 2026-08-12 | v1 | 初始需求 |

## 用户故事

- 作为访客，我想要在首页快速了解 Web3 University 的价值主张和平台规模，以便判断是否值得进一步浏览课程。
- 作为访客，我想要理解「领取 YD → 购买课程 → 铸造证书」的学习路径，以便知道平台的使用流程。
- 作为访客，我想要在首页看到精选课程入口，以便直接跳转查看感兴趣的课程。

## 功能需求

1. [F-001] Hero 区块：中英文标题「学习 Web3，拥有你的学习成果」、平台定位文案、两个 CTA 按钮（浏览课程 / 连接钱包）。
2. [F-002] 关键指标区块：三张统计卡（学生数 12,000+、课程数 45+、链上证书数 8,000+）。
3. [F-003] 学习路径区块：三步骤图示（1. 领取 YD 测试代币 2. 使用 YD 购买课程 3. 完课铸造 ERC-721 证书）。
4. [F-004] 精选课程区块：至少两张课程卡（如「Solidity 智能合约入门」「DeFi 与 Uniswap 实战」），展示封面、标题、周期/难度、价格。
5. [F-005] 「连接钱包」CTA 触发 Mock 钱包 `connect()`，触发后 `TopNav` 钱包状态徽标同步变为已连接态。
6. [F-006] 「浏览课程」CTA 跳转至课程广场页面路由。

## 非功能需求

- 性能: 首屏（Hero + 指标区）应在无网络请求阻塞的情况下快速渲染（全部为静态 Mock 数据）。
- 安全: 无（本页面无敏感操作）。
- 兼容性: 桌面/平板/移动三档断点下各区块正确堆叠，不出现横向溢出。

## 验收标准

- [ ] [AC-001] 首页在桌面宽度下与 Stitch 截图的整体区块顺序、文案一致（Hero → 指标 → 学习路径 → 精选课程 → Footer）。
- [ ] [AC-002] 点击「连接钱包」后，页面内 CTA 与 `TopNav` 徽标均反映已连接状态。
- [ ] [AC-003] 点击「浏览课程」正确跳转到课程广场路由。
- [ ] [AC-004] 移动端宽度下各区块单列堆叠，无内容截断或横向滚动条。
