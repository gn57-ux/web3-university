# 响应式与视觉 QA — 需求规格

## 概述

对 feature 2-8 已实现的全部页面进行跨断点响应式走查与视觉一致性核验，对照 Stitch 原始设计稿修复发现的问题，产出 QA 总结报告。

## 项目信息

- 项目名: web3-university
- 架构类型: 单体仓库：Next.js 前端（纯 UI + Mock 交互）

## 需求版本

| 日期 | 版本 | 说明 |
| --- | --- | --- |
| 2026-08-12 | v1 | 初始需求 |

## 用户故事

- 作为项目负责人，我想要确认所有页面在桌面/平板/移动三档断点下均可正常使用，以便保证真实用户在不同设备上的体验。
- 作为项目负责人，我想要确认实现的视觉效果（配色/字体/圆角/间距）与 Stitch 设计稿保持一致，以便交付质量可控。

## 功能需求

1. [F-001] 建立响应式测试矩阵：桌面（≥1280px，对应设计系统 12 列网格）、平板（768-1279px，8 列）、移动（<768px，4 列）。
2. [F-002] 对首页、课程广场、课程详情三个页面逐一走查，对照 Stitch 截图核查间距、字号、断行、组件堆叠顺序。
3. [F-003] 对学习中心、个人中心两个页面逐一走查，重点核查视频区/章节列表、Tab/表格在小屏下的可用性。
4. [F-004] 对老师工作台、Owner 后台两个页面逐一走查，重点核查侧边栏、表单、管理表格在小屏下的可用性。
5. [F-005] 视觉一致性核验：暗色模式配色是否统一、Sora/Inter/JetBrains Mono 三字体是否按场景正确应用、圆角与间距是否符合 feature 1 定义的设计令牌。
6. [F-006] 对走查中发现的问题逐项修复，并复查确认修复有效。
7. [F-007] 产出 QA 总结报告，记录已核验页面范围、测试断点、发现并修复的问题、遗留问题（如有）。

## 非功能需求

- 性能: 不涉及。
- 安全: 不涉及。
- 兼容性: 本 feature 本身即是兼容性验收环节。

## 验收标准

- [ ] [AC-001] 全部 7 个页面（首页/课程广场/课程详情/学习中心/个人中心/老师工作台/Owner 后台）均完成三档断点走查并记录结果。
- [ ] [AC-002] 走查中发现的问题均已修复或在报告中明确标注为遗留问题及原因。
- [ ] [AC-003] 视觉一致性核验通过，无明显偏离设计令牌的配色/字体/圆角使用。
- [ ] [AC-004] 产出的 QA 总结报告清晰列出核验范围、断点、问题与修复情况。
